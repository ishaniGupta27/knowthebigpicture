Create a curiosity-led answer to a WHY question.

Silently write the direct answer in one ordinary sentence. Select only the links
needed to make that sentence satisfying:

question -> immediate answer -> where the cause starts -> what happens ->
recognizable result -> useful payoff

Use only the links the topic needs. Do not turn a simple curiosity into a complete
science, history, or engineering lesson. Stop at the first satisfying explanation.
End with the clearest result or implication, not unrelated trivia.

Use 5-6 slides total, including the opening question slide.

### Opening hook (narration, question slide)
Name something the viewer has seen but never questioned, then ask why. Keep it to
6-12 words; lead with the thing, not a wind-up.
Openers (punchy): "X happens every day. But why?", "Everyone's seen X. Almost
no one knows why."
